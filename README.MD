Suggestions to configure your game while using this resoucepack:

> Ammendments > Client > Jukebox > Disc Spin

Turn on Texture Pack Support: provides help for textures not provided by this pack and attemps to make dynamic custom textures. (Already configured that the base vanilla textures will fit but modded can be applyed aswell)
> Ammendments > Client > General > Texture Pack Support
> Supplementaries > Client > General > Dynamic Assets Generation Mode

Turning off Pixel Consistent Signs in Ammendments if you prefer the classic sign textures
> Ammendments > Client > Sign > Pixel Consistent
