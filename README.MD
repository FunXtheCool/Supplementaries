Goal behind this pack is to not break immersion when I use ashen in modded minecraft modpacks! With a long term Goal of Having compatability to most commonly used mods.

Since that's the Main Target for this pack is Supplementarys it's in the name but this also bundles supp^2 and Amendments, as Supplementaries tend to have lots of overlap between them.

### Mod Configurations 
If using the ammendments part of this pack Turn off disc Rotations.
- `Ammendments > Client > Jukebox > Disc Spin`

Turning off Pixel Consistent Signs in Ammendments if you prefer the classic sign textures
- `Ammendments > Client > Sign > Pixel Consistent`

Turn on Texture Pack Support: provides help for textures not provided by this pack and attemps to make dynamic custom textures. 
> (Already configured that the base vanilla textures will fit but modded can be applyed aswell at the cost and cpu increese at startup)
- `Supplementaries > Client > General > Dynamic Assets Generation Mode`
- `Ammendments > Client > General > Texture Pack Support`
